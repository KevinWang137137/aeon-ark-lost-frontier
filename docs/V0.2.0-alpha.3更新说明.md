# V0.2.0-alpha.3 更新说明

本版聚焦工程可靠性与可验证性。

1. 新增 scripts/validate_quests.py，离线检查任务 JSON、JustQuests 目标/奖励字段、必需字段、任务前置关系和数据包元信息。
2. 为本地完整文件 ZIP 增加构建后清点：确认 mods/ 内存在已下载并校验哈希的 JAR。
3. 确认 Global Packs 使用实例内 global_packs/required_data/；enable_system_global_packs=false 只关闭用户级公共目录，不会关闭实例内必需数据包。
4. 锁定 Minecraft Java 26.3、Fabric Loader 0.20.1、Fabric API 0.166.2+26.3、Java 25 x64。

## 验收边界
- 已做：72 条任务 JSON 静态校验、8 类任务统计、任务前置完整性检查、压缩包完整性检查。
- 未做：Windows PowerShell 实际下载、完整依赖闭包测试、PCL 导入、Minecraft 客户端启动、海岛出生点实测、逐任务计数测试、5GB 长期稳定性测试。
- 因此 Alpha 3 是工程预览版，不是已验收可玩的发行版。
