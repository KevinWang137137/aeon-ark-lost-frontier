# V0.2.0-alpha.3 更新说明

1. 新增 JustQuests 任务静态校验脚本，并将 72 条任务以 GZip + Base64 JSON bundle 形式存入仓库；可还原为数据包目录。
2. 为本地完整文件 ZIP 增加构建后 JAR 清点，避免空壳包被报告成功。
3. 将 Biomes O' Plenty 从必装模组清单移除：Modrinth 当前展示的是 Modpack 条目，不应作为普通 JAR 模组处理。
4. 用 Terralith 2.6.5+26.3 作为可选群系数据包，并把 Dungeons & Taverns 也放入 optional_data。
5. Global Packs 的 enable_system_global_packs=false 是实例隔离设置；实例内 required_data 仍由 [datapacks].required 自动加载。

## 验收边界
- 已做：72 条任务 JSON 静态校验、8 类任务统计、任务前置完整性检查、pack.mcmeta 格式检查、源码 ZIP 完整性检查。
- 未做：Windows PowerShell 实际下载、完整依赖闭包测试、PCL 导入、客户端启动、小岛出生点验收、逐任务计数和 5GB 稳定性测试。
