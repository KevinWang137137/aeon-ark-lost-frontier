## 重要修订
Modrinth 的 Biomes O' Plenty 页面实际路径为 /modpack/biomes-o-plenty。它不是本项目应当下载的普通 Fabric 模组 JAR。因此从 required_mods 移除。Terralith 改为可选数据包：世界生成变化可能影响特殊小岛，须分别测试启用/关闭后的出生点和资源可持续性。

上表表示各项目页面存在相应 26.3/Fabric 发布记录，不等同于已经完成本整合包组合的启动、世界生成或性能测试。构建脚本仍需在 Windows 联网环境解析实际文件和依赖，并验证哈希。
