# 下一步开发路线

## 阶段 A：构建与启动验收
- 在 Windows 联网环境运行 Build_PCL整合包.bat。
- 核对所有必需模组和依赖的 Minecraft 26.3 / Fabric 版本。
- 用 PCL 新建隔离实例并启动到主菜单。
- 创建测试世界，检查 Global Packs / JustQuests 是否加载。

## 阶段 B：小岛开局
- 实际检查候选种子与出生点。
- 检查岛屿面积、海洋包围情况、树木/石材/食物资源与可持续性。
- 若自然种子不能满足要求，制作专用起始岛地图或稳定的世界生成方案。

## 阶段 C：玩法实测
- 在游戏内逐条检查 72 个任务的目标计数、前置和奖励。
- 检查 Ala Industrial 与 Spellgems 的真实物品 ID、合成配方和进度。
- 检查新群系、生物、结构分布以及模组冲突。

## 阶段 D：扩展内容
- 把任务从 72 扩至 360+，保持独立专题线与主线里程碑汇合。
- 扩充文物图鉴、隐藏档案、建筑奖励和五条结局路线。
- 以实测结果决定后续可选模组，避免牺牲稳定性与 5GB 内存目标。
