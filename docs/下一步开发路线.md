# 下一步开发路线

## A. 构建与启动验收
- 在 Windows 联网环境运行 Build_PCL整合包.bat。
- 核对所有必需模组和依赖的 Minecraft 26.3 / Fabric 文件。
- 使用 PCL 新建隔离实例并启动至主菜单。
- 创建测试世界，确认 Global Packs / JustQuests 正常加载。

## B. 特殊小岛开局
- 分别测试原版地形与 Terralith 可选数据包。
- 检查岛屿面积、海洋包围情况、树木/石材/食物资源和可持续性。
- 若自然种子不能满足要求，制作专用起始岛地图。

## C. 玩法验收
- 实际检查 72 条任务目标、前置和奖励。
- 核验 Ala Industrial、Spellgems 的物品 ID、配方和进度。
- 检查新增群系、生物、结构分布及模组冲突。

## D. 扩充内容
- 从 72 条任务扩至 360+。
- 扩充文物图鉴、隐藏档案、建筑奖励和五种结局。
- 以实测结果确定可选模组，维持易上手和约 5GB 内存目标。
